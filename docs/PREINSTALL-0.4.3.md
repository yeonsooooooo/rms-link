# 0.4.3 설치·배포 검증 기록

2026-09-26에 운영 Mac mini에 SSH로 접속하여 Windows 검증을 통과한 0.4.3을 배포했습니다. 관리 서버와 공통 판독 실행기를 갱신하고, 자동 업데이트 패키지 및 고객용 설치 EXE를 게시했습니다.

## 변경

- 중첩된 표와 ValuePattern 셀 값을 읽고, DataGridView가 각 셀을 별도 항목으로 노출해도 같은 표의 화면 좌표로 행을 재구성합니다.
- 로그 영역 내부의 직접 읽기와 OCR을 병행합니다. 비밀번호와 영역 밖 텍스트는 제외합니다.
- 불확실한 객실·항목만 보류하고 정상 객실은 계속 전송합니다. 충돌한 OCR 프레임은 다음 판독의 확인 근거에서 제외합니다.
- 트레이·미리보기·대시보드에 글자 수와 채택 상태 수, 확인이 필요한 원인을 표시합니다. 문제가 지속되면 Windows 알림을 표시하며 진단 파일에도 남깁니다.

## 통과한 검증

- 공통 C# 검사 104개, 서버 검사 24개, Windows 빌드.
- 실제 Windows 시험 창의 중첩된 표·DataGridView 셀 값·선택 영역·비밀번호 제외와 기존 OCR·가림·최소화 복구 검사.
- 암호화 대기열과 HTTP 시간 초과 복구, 업데이트 사전 검사가 기존 키텍 바로가기를 보존하는지 확인.
- 일반 설치 UI, 재설치 시 설정 보존, 실행 실패 시 이전 버전 보존, 독립 진단 수집.
- 배포할 EXE 자체를 Windows에서 내려받아 해시 대조 후 설치·설치된 앱 실행·한글 설정 바로가기·자동 시작 확인.
- 게시된 설치 EXE의 전체 다운로드 크기·SHA-256 대조.
- HTTPS 기기 등록·연결 보고·RSA 서명 업데이트 안내·실제 업데이트 패키지 크기와 해시 대조. 임시 확인 기기는 삭제했습니다.
- 외부 대시보드 진입·인증·권한·동일 데이터·실시간 연결·다운로드 확인.
