# 첫 호텔 현장 확인

1. Windows 설치 파일 실행 → 실제 hotel_id 입력 → 바탕화면 키텍 아이콘 선택 → 실제 창 미리보기 확인 → 연결.
2. 대시보드에 호텔과 PC가 나타나는지 확인합니다. `관측 대기` 또는 `확인 필요`면 기기 행을 눌러 원인을 확인합니다.
3. ‘RMS 창을 찾지 못함’이면 **키텍 앱 선택 · 변경**으로 실제 창을 선택합니다. 필요하면 **로그 영역 다시 지정**으로 객실 번호·문/키 상태·시각을 포함하는 로그 영역을 선택합니다. 다른 호텔로 바꿀 때 이전 지정 영역은 초기화됩니다.
4. 시험 객실 한 곳에서 다음 실제 동작을 순서대로 수행하고 대시보드 이벤트·원문·발생 시각과 대조합니다.
   - 문 열기 → `DOOR_OPEN`
   - 문 닫기 → `DOOR_CLOSE`
   - 손님 키 꽂기 → `KEY_IN` 또는 `KEY_IN_GUEST`
   - 키 빼기 → `KEY_OUT` 또는 `KEY_OUT_GUEST`
   - 청소키가 구분되는 환경에서는 청소키 삽입·제거도 별도 확인합니다.
5. 잘못되거나 누락된 원문을 기기 상세의 **확인한 판독 샘플 등록**에 기록하고 **지금 화면 분석**을 누릅니다.
6. `프로필 배포` 이후 Windows의 프로필 revision이 증가했는지 확인하고 같은 동작을 반복합니다. 수동으로 바로 받으려면 트레이에서 **지금 업데이트 확인 · 적용**을 누릅니다.
7. 인터넷을 잠시 끊었다 연결해 전송 대기 수가 줄어드는지 확인합니다. 앱을 종료했다 다시 실행해도 이전 전송 자료는 보존됩니다.

설치·기기 연결·OCR 판독·문/키 상태 정확성은 서로 다른 단계입니다. 현재 호텔에서 위 네 가지 동작이 모두 일치하기 전에는 키텍 연동 검증 완료로 기록하지 않습니다.
